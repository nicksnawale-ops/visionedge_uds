VisionEdge login background photos
==================================

Optional full-bleed photos for the Login Page template. Drop a file here named after
its use case and the login screen uses it automatically (with a Deep Navy 72% overlay).
If a file is missing or fails to load, the screen falls back to the line-art illustration.

File names
  generic.webp       Camera / control-room context
  anpr.webp          Gate with vehicles
  hosteltrack.webp   Hostel exterior
  mealpulse.webp     Canteen / dining hall
  visitor.webp       Campus entrance / visitor gate

Requirements
  - 1920 × 1080 px, WebP format, under 300 KB
  - A real, relevant scene for the use case (see list above)
  - No visible faces and no readable real number plates
  - Avoid very bright or busy images; the overlay keeps the card readable, but calm scenes work best

Preview a photo
